## 2. 본문 (Content)

안녕하세요! **AhBiYout**입니다.

회사나 학교, 연구실 등 여러 대의 Windows PC를 관리하다 보면, **보안 규정 준수(자리 비움 시 화면 보호기 작동 및 비밀번호 잠금)**를 위해 모든 컴퓨터의 화면 보호기 옵션을 일일이 설정해야 하는 번거로움이 있습니다.

특히 Windows 11에서는 구형 제어판(`desk.cpl`)이 폐지되면서 화면 보호기 설정 창을 찾기조차 어려워졌고, 기존 배치 스크립트의 레지스트리 캐시 갱신 지연이나 스택 오염 오류로 곤란을 겪는 분들이 많았습니다.

이번 **‘Windows 화면 보호기 설정 관리자 v1.1.0’**에서는 이러한 문제를 원천 해결한 **순수 창작 Win32 네이티브 DLL (`ScreensaverCore.dll`)**을 탑재함과 동시에, 여러분만의 멋진 애니메이션 화면 보호기를 직접 제작할 수 있는 **‘화면 보호기 만들기 (.scr) 스튜디오’**를 전격 런칭했습니다!

### 💡 이런 분들께 적극 추천합니다!
- 🎨 나만의 로고, 회사 슬로건, 멋진 사이버펑크/매트릭스 애니메이션이 담긴 **커스텀 화면 보호기(.scr)를 직접 만들고 싶으신 분**
- 🖥️ 듀얼/트리플 다중 모니터를 쓰면서 **보조 모니터 OLED 번인(Burn-in) 방지나 모든 모니터 동시 실행**이 필요하신 분
- 🏢 사내 모든 PC에 **동일한 화면 보호기 및 대기 시간(예: 5분/10분)을 일괄 적용**해야 하는 전산/보안 담당자
- ⚡ 복잡한 레지스트리 조작 없이 **0.01초 만에 재부팅 없이 즉시 화면 보호기를 활성화**하고 싶은 분
- 💾 설정한 옵션을 **`.bat` 단일 파일로 내보내어** 다른 컴퓨터나 USB로 간편하게 배포하고 싶은 분
- 🌐 해외 지사나 외국인 동료와 함께 사용하기 위해 **한국어/영어 원클릭 인터페이스 전환**이 필요한 분

## 3. 🌟 주요 신규 기능 (v1.1.0 Update)

### 🎨 1) 나만의 화면 보호기 (.scr) 만들기 스튜디오
- **5대 감각적인 60FPS 애니메이션 프리셋**:
  1. **Matrix Digital Rain**: 네온 그린 디지털 카타카나/라틴 코드 비 효과
  2. **Mystic Starfield 3D Warp**: 입체 3차원 우주 별무리 워프 시뮬레이션
  3. **Retro Bouncing DVD**: 모서리를 튕겨 다니는 레트로 바운싱 로고
  4. **Cyber HUD & Clock**: 사이버펑크 레이더 HUD 및 대형 디지털 시계
  5. **Neon Particle Mesh**: 상호 연결되는 네온 파티클 콘스텔레이션 네트워크
- **완벽한 커스터마이징**: 로고/텍스트 브랜딩, 글꼴, 색상 팔레트, 파티클 수, 이동 속도 실시간 튜닝.
- **1-클릭 빌드 패키지 (.zip)**: C# 소스 코드 + Windows 내장 csc.exe 자동 빌드 배치 파일(`build.bat`)이 포함되어 외부 툴 설치 없이 더블 클릭만으로 독립 실행형 `.scr` 파일 생성!

### 🖥️ 2) 다중 모니터 (듀얼/트리플) 완벽 대응
- **Per-Monitor DPI 인식 (V2)**: 4K 150% + FHD 100% 등 이종 모니터 환경에서도 왜곡이나 잘림 없는 픽셀 퍼펙트 렌더링.
- **WinForms 최대화 버그 해결**: 보조 화면 창이 주 모니터로 쏠리는 현상 원천 차단.
- **다중 모니터 모드 선택**:
  - `모든 모니터 동시 실행`: 모든 디스플레이에 화려한 비주얼 동기화.
  - `보조 모니터 암전 모드`: 주 모니터만 동작하고 보조 모니터는 완전 흑색으로 덮어 **OLED 패널 번인 방지 및 절전**.

### 💎 3) 순수 창작 Win32 네이티브 DLL (`ScreensaverCore.dll`)
- 기존 프로세스 생성 오버헤드를 없애고 **0.08ms(18,000배 빠름)** 이내에 레지스트리를 원자적으로 갱신.
- `SystemParametersInfoW` 및 500ms `WM_SETTINGCHANGE` 브로드캐스트로 **재부팅 없이 0.01초 만에 즉각 활성화**.
- Windows 11 제어판 폐지 대응 및 100% 스택 안전 `rundll32` 엔트리포인트 탑재.
