## 2. 본문 (Content)

안녕하세요! **AhBiYout**입니다.

회사나 학교, 연구실 등 여러 대의 Windows PC를 관리하다 보면, **보안 규정 준수(자리 비움 시 화면 보호기 작동 및 비밀번호 잠금)**를 위해 모든 컴퓨터의 화면 보호기 옵션을 일일이 설정해야 하는 번거로움이 있습니다.

특히 Windows 10과 11에서는 제어판 경로가 깊숙이 숨겨져 있어 화면 보호기 설정 창을 찾는 것조차 번거로운 경우가 많은데요. 이러한 불편을 한 번에 해결하고자 **‘Windows 화면 보호기 설정 관리자(v1.0.9)’**를 직접 개발하여 무료로 배포합니다!

### 💡 이런 분들께 적극 추천합니다!
- 🏢 사내 모든 PC에 **동일한 화면 보호기 및 대기 시간(예: 5분/10분)을 일괄 적용**해야 하는 전산/보안 담당자
- 🔒 자리를 비울 때 개인정보 보호를 위해 **자동 화면 잠금(암호 보호)**을 확실하게 걸어두고 싶은 개인 사용자
- ⏱️ 복잡한 레지스트리 조작 없이 **클릭 한 번으로 윈도우 화면 보호기를 켜고 끄고 싶은 분**
- 💾 설정한 옵션을 **`.bat` 단일 파일로 내보내어** 다른 컴퓨터나 USB로 간편하게 배포하고 싶은 분
- 🌐 해외 지사나 외국인 동료와 함께 사용하기 위해 **한국어/영어 인터페이스 전환**이 필요한 분

### 🌟 핵심 기능 안내
1. **🌐 한국어 / 영어 (KO/EN) 실시간 전환**: 상단 헤더의 언어 전환 버튼을 통해 한국어와 영어 모드를 자유롭게 전환할 수 있습니다. (설정 자동 저장)
2. **실시간 현재 설정 감지**: 프로그램을 켜면 현재 PC의 화면 보호기 작동 여부, 대기 시간, 암호 보호 상태를 레지스트리에서 자동 판독하여 화면 상단에 표시합니다.
3. **손쉬운 옵션 커스텀**:
   - 화면 보호기 On/Off 토글
   - Windows 기본 지원 보호기(3D 텍스트, 비눗방울, 갈고리 상자, 리본, 사진 등) 완벽 지원
   - 사용자 지정 `.scr` 파일 등록 지원
   - 대기 시간(0분~60분) 5분 단위 세밀 조절
   - 화면 복귀 시 비밀번호 잠금(로그온 화면 표시) 설정
4. **원클릭 시스템 즉시 적용**: [설정 적용] 클릭 시 Windows 레지스트리가 즉시 변경되고 Win32 시스템 파라미터가 동기화되어 재부팅 없이 바로 적용됩니다.
5. **독립 실행 배치(.bat) 파일 생성**: [다운로드] 버튼을 누르면 다른 PC에서도 더블 클릭만으로 동일한 설정이 적용되는 `.bat` 배치 파일이 안전하게 저장됩니다.

## 3. 업데이트 (Update - v1.0.9)

최신 **v1.0.9** 버전에서 개선된 주요 내용입니다:

- **🌐 한국어 / English (KO/EN) 원클릭 언어 전환 지원**:
  - 상단 헤더 우측에 다국어 토글 버튼을 추가하여 전체 화면의 언어를 한국어와 영어로 즉시 전환할 수 있습니다.
  - 사용자가 선택한 언어는 자동 저장되어 재실행 시에도 유지됩니다.
- **Tauri 프레임워크 및 빌드 패키지 버전 정합성 강화**:
  - Rust 크레이트(`tauri v2.11.1`, `tauri-build v2.6.3`)와 프론트엔드 NPM 패키지 버전 불일치 문제를 원천 차단했습니다.
- **포트 기본값 충돌 방지**:
  - 빌드 및 로컬 테스트 시 타 앱과의 충돌을 피하기 위해 기본 포트를 `3036`으로 최적화하였습니다.

## 6. 시스템 요구 사항 (System Requirements)

- **운영체제**: Microsoft Windows 10 (64-bit) / Windows 11 (64-bit)
- **웹뷰 런타임**: Microsoft Edge WebView2 Runtime (Windows 10/11에 기본 탑재되어 있음)
- **권한**: Windows 레지스트리(Current User) 변경 권한 (일반 사용자 권한으로 즉시 실행 가능, 관리자 권한 불필요)
- **저장 공간**: 15MB 이하의 여유 디스크 공간
