## 1. 개요 및 화면 구성

앱을 실행하면 상단에서 현재 사용자 PC에 적용되어 있는 실제 Windows 화면 보호기 설정을 실시간으로 확인할 수 있습니다.

### 주요 화면 요소
1. **상단 정보 바 (현재 윈도우 설정)**
   - **상태**: 켜짐 / 꺼짐
   - **종류**: 현재 설정된 화면 보호기 파일 이름 (예: 갈고리 상자, 3D 텍스트 등)
   - **대기**: 화면 보호기가 동작하기까지 걸리는 대기 시간 (분)
   - **암호**: 화면 보호기 마우스 이동 해제 시 로그온(비밀번호) 화면 표시 여부

2. **설정 조작 패널**
   - **화면 보호기 켜기 토글**: 화면 보호기 활성화/비활성화
   - **화면 보호기 종류 드롭다운**: Windows 기본 화면 보호기 선택 또는 사용자 지정(`.scr`) 파일 업로드
   - **대기 시간 선택**: 0분(즉시) ~ 60분 (5분 간격)
   - **로그온 화면 표시 토글**: 해제 시 암호 입력 요구 설정

3. **스크립트 미리보기 및 실행 패널**
   - 현재 설정값에 따라 실시간 생성되는 Windows 배치 스크립트 미리보기
   - **[복사]**: 생성된 배치 스크립트 텍스트를 클립보드로 복사
   - **[설정 적용]**: 현재 PC 시스템에 선택한 설정을 즉시 적용
   - **[.bat 다운로드]**: 지정된 설정이 담긴 배치 스크립트 파일(`.bat`)을 원하시는 경로에 다운로드

## 2. 세부 기능 사용 가이드

### 2.1 현재 PC 시스템에 즉시 적용하기
1. 사용하고자 하는 화면 보호기 활성화 토글, 종류, 대기 시간, 암호 요구 여부를 선택합니다.
2. 하단의 **[설정 적용]** 버튼을 클릭합니다.
3. 안내 확인 창이 나타나면 **[적용하기]**를 클릭합니다.
4. 레지스트리가 즉시 수정되고, 시스템 파라미터가 동기화되어 화면 보호기 설정이 새로고침됩니다.

### 2.2 `.bat` 배치 파일 생성 및 내보내기 (Download)
1. 세팅하고자 하는 화면 보호기 옵션을 구성합니다.
2. 하단의 **[.bat 다운로드]** 버튼을 누릅니다.
3. Windows 네이티브 **'다른 이름으로 저장'** 다이얼로그 창이 실행됩니다.
4. 원하시는 저장 경로(예: 바탕 화면, 문서, USB 드라이브 등)와 파일 이름을 지정한 후 **[저장]**을 누릅니다.
5. 생성된 `.bat` 파일은 다른 Windows PC에서도 관리자 권한으로 실행하면 동일한 화면 보호기 설정이 적용됩니다.

### 2.3 커텀 화면 보호기 (.scr) 등록하기
1. 화면 보호기 종류 선택 드롭다운에서 **[사용자 지정 (.scr 파일)]**을 선택합니다.
2. 아래 나타나는 **[.scr 파일 선택]** 영역을 클릭하여 소유하고 계신 `.scr` 확장자 파일을 업로드합니다.

## 3. 스크립트 인코딩 및 호환성 사양

본 프로그램이 생성하는 배치 스크립트는 Windows 커맨드 프롬프트(cmd.exe) 환경에서 가장 안정적으로 동작하도록 아래 사양을 준수합니다.

- **줄바꿈 (Line Ending)**: `CRLF (\r\n)` - Windows 표준 개행
- **문자 인코딩 (Encoding)**: `UTF-8` (BOM 없음)
- **코드페이지 자동 전환**: 스크립트 상단에 `@chcp 65001 >nul` 구문이 삽입되어 한글이 포함된 에러 메시지 및 출력문이 깨짐 없이 표시됩니다.

## 4. 자주 묻는 질문 (FAQ) & 문제 해결

### Q1. `.bat` 파일을 내려받을 때 지정한 폴더가 아닌 다운로드 폴더에 저장되거나 앱 종료 시 삭제되나요?
> **A:** 과거 브라우저 다운로드 방식에서 발생했던 문제입니다. 현재 버전에서는 Rust 백엔드가 네이티브 파일 다이얼로그(`rfd`)를 직접 제어하여 사용자가 지정한 위치에 영구적으로 안전하게 저장됩니다.

### Q2. 스크립트 실행 후 시스템 적용에 약간의 시간이 걸리나요?
> **A:** 스크립트 실행 시 레지스트리 수정 후 PowerShell 및 `SystemParametersInfo` Win32 API를 호출하여 Windows GUI 세션에 즉시 동기화 신호를 보냅니다. 보통 1초 이내에 반영됩니다.

### Q3. 다른 PC에 배치 파일을 전달하여 실행할 수 있나요?
> **A:** 네, 내보내기한 `.bat` 파일은 단독 실행 가능한 Windows 스크립트이므로 다른 Windows 10/11 PC에서도 동일하게 실행하여 화면 보호기 설정을 일괄 적용할 수 있습니다.
