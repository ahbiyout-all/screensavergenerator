## 1. 개요 및 화면 구성

앱을 실행하면 상단에서 현재 사용자 PC에 적용되어 있는 실제 Windows 화면 보호기 설정을 실시간으로 확인할 수 있으며, 신규 화면 보호기 제작 스튜디오와 Win32 네이티브 DLL 엔진을 즉시 활용할 수 있습니다.

### 주요 화면 요소
1. **상단 네비게이션 헤더**
   - **[✨ 화면 보호기 만들기 (.scr)] 버튼**: 나만의 Windows 화면 보호기 제작 스튜디오 모달을 오픈합니다.
   - **[💎 DLL Core] 버튼**: 순수 창작 Win32 네이티브 DLL(`ScreensaverCore.dll`)의 기술 사양 및 rundll32 명세서를 확인합니다.
   - **버전 배지 (`v1.1.0`)**: 클릭 시 GitHub Releases 실시간 업데이트 확인 팝업을 호출합니다.
   - **언어 토글 (`KO / EN`)**: 한국어와 영어 모드를 원클릭으로 실시간 전환합니다.

2. **상단 정보 바 (현재 윈도우 설정)**
   - **상태**: 켜짐 / 꺼짐
   - **종류**: 현재 설정된 화면 보호기 파일 이름 (예: 갈고리 상자, 3D 텍스트 등)
   - **대기**: 화면 보호기가 동작하기까지 걸리는 대기 시간 (분)
   - **암호**: 화면 보호기 마우스 이동 해제 시 로그온(비밀번호) 화면 표시 여부

3. **설정 조작 패널**
   - **화면 보호기 켜기 토글**: 화면 보호기 활성화/비활성화
   - **화면 보호기 종류 드롭다운**: Windows 기본 화면 보호기 선택 또는 사용자 지정(`.scr`) 파일 업로드
   - **[미리보기 테스트 (Preview)] 버튼**: 선택된 화면 보호기를 현재 모니터에서 즉시 전체화면으로 테스트
   - **대기 시간 선택**: 0분(즉시) ~ 60분 (5분 간격)
   - **로그온 화면 표시 토글**: 해제 시 암호 입력 요구 설정

4. **스크립트 미리보기 및 실행 패널**
   - 현재 설정값에 따라 실시간 생성되는 Windows 배치 스크립트 미리보기
   - **[복사]**: 생성된 배치 스크립트 텍스트를 클립보드로 복사
   - **[설정 적용]**: 현재 PC 시스템에 선택한 설정을 즉시 적용
   - **[.bat 다운로드]**: 지정된 설정이 담긴 배치 스크립트 파일(`.bat`)을 원하는 경로에 안전하게 다운로드

## 2. 세부 기능 사용 가이드

### 2.1 현재 PC 시스템에 즉시 적용하기
1. 사용하고자 하는 화면 보호기 활성화 토글, 종류, 대기 시간, 암호 요구 여부를 선택합니다.
2. 하단의 **[설정 적용]** 버튼을 클릭합니다.
3. 안내 확인 창이 나타나면 **[적용하기]**를 클릭합니다.
4. 레지스트리가 즉시 수정되고, 시스템 파라미터가 동기화되어 화면 보호기 설정이 새로고침됩니다.

### 2.2 `.bat` 배치 파일 생성 및 내보내기 (Download)
1. 세팅하고자 하는 화면 보호기 옵션을 구성합니다.
2. 하단의 **[.bat 다운로드]** 버튼을 누릅니다.
3. Windows 네이티브 **'다른 이름으로 저장'** 다이얼로그 창이 실행됩니다.
4. 원하는 저장 경로(예: 바탕 화면, 문서, USB 드라이브 등)와 파일 이름을 지정한 후 **[저장]**을 누릅니다.
5. 생성된 `.bat` 파일은 다른 Windows PC에서도 더블 클릭(또는 관리자 권한)으로 실행하면 동일한 화면 보호기 설정이 적용됩니다.

### 2.3 커스텀 화면 보호기 (.scr) 등록 및 미리보기
1. 화면 보호기 종류 선택 드롭다운에서 **[사용자 지정 (.scr 파일)]**을 선택합니다.
2. 아래 나타나는 **[.scr 파일 선택]** 영역을 클릭하여 소유하고 계신 `.scr` 확장자 파일을 업로드합니다.
3. 옆의 **[미리보기 테스트]** 버튼을 누르면 해당 화면 보호기가 즉시 전체화면으로 실행되어 동작을 검증할 수 있습니다.

## 3. 🎨 화면 보호기 만들기 (.scr) 스튜디오 사용 가이드

상단 헤더의 **[✨ 화면 보호기 만들기 (.scr)]** 버튼을 클릭하면 나만의 독립 실행형 Windows 화면 보호기를 제작할 수 있는 스튜디오가 열립니다.

### 3.1 5대 애니메이션 테마 프리셋
* **Matrix Digital Rain**: 영화 매트릭스 스타일의 네온 그린 디지털 카타카나/라틴 코드 비 낙하 효과.
* **Mystic Starfield 3D Warp**: 우주 공간을 워프 항해하는 3차원 별무리 입체 시뮬레이션.
* **Retro Bouncing DVD Logo**: 추억의 DVD 플레이어 대기 화면처럼 모니터 모서리를 튕겨 다니는 네온 로고.
* **Cyber HUD & Clock**: 사이버펑크 감성의 고정밀 원형 레이더 HUD, 시스템 모니터링 게이지 및 대형 디지털 시계.
* **Neon Particle Mesh**: 마우스와 인터랙션하며 서로 선으로 연결되는 감각적인 네온 파티클 네트워크.

### 3.2 비주얼 & 브랜딩 커스터마이징
* **로고 및 보조 문구**: 원하는 회사명, 이니셜, 슬로건을 입력하여 화면 보호기 중앙에 노출.
* **글꼴(Font)**: Consolas, Segoe UI, Impact, Courier New 등 선택 가능.
* **색상 팔레트**: 사이버 그린, 딥 시안, 네온 퍼플, 앰버 골드, 레트로 핑크 등 주 색상과 보조 색상 자유 선택.
* **파티클 수 & 속도**: 20개~300개 입자 수 및 슬라이더를 통한 프레임 속도 미세 조절.
* **실시간 60FPS 캔버스**: 설정값을 바꿀 때마다 우측(또는 상단) 미리보기 캔버스에서 실시간 렌더링 확인.

### 3.3 🖥️ 다중 모니터 (듀얼/트리플) 모드 설정
모니터가 2대 이상인 환경을 위해 전용 멀티 모니터 엔진 옵션을 제공합니다:
1. **모든 모니터 동시 애니메이션 실행 (권장)**:
   - 연결된 모든 모니터(`Screen.AllScreens`)에 각각 독립된 창을 생성하여 끊김 없이 일체감 있는 화면 보호기를 구동합니다.
2. **주 모니터만 애니메이션 + 보조 모니터 암전**:
   - 주 모니터에서만 화려한 애니메이션이 실행되고, 보조 모니터들은 완전한 블랙 스크린(`Color.Black`)으로 덮입니다.
   - **OLED 디스플레이의 번인(Burn-in)을 원천 방어**하고 전력 소비를 최소화합니다.

### 3.4 1-클릭 패키지 다운로드 및 빌드 방법
1. 스튜디오 하단의 **[1-클릭 빌드 패키지 (.zip) 다운로드]** 버튼을 클릭합니다.
2. 다운로드된 ZIP 파일 안에는 다음 파일들이 포함되어 있습니다:
   - `Program.cs` : 완성된 C# 화면 보호기 전체 소스 코드 (Win32 P/Invoke, DPI Aware, 다중 모니터 엔진 포함)
   - `build.bat` : Windows에 기본 내장된 `csc.exe` 컴파일러를 자동 탐색하여 1초 만에 `.scr`을 빌드하는 배치 파일
   - `README.txt` : 설치 및 등록 가이드
3. 압축 해제 후 `build.bat`을 더블 클릭하면 즉시 무설치 화면 보호기 실행 파일(`.scr`)이 생성됩니다!
4. 생성된 `.scr` 파일을 마우스 우클릭한 후 **[설치]**를 누르면 Windows 화면 보호기 목록에 영구 등록됩니다.

## 4. 💎 순수 창작 Win32 DLL (`ScreensaverCore.dll`) 연동

Windows 11에서 기존 제어판(`desk.cpl`)이 삭제되고, `rundll32 user32.dll` 호출 시 스택 오염(0xC0000005) 오류가 발생하던 문제를 해결하기 위해 본 프로젝트 전용 네이티브 DLL을 개발하여 내장했습니다.

* **초고속 원자적 갱신**: 레지스트리 수정 및 Win32 브로드캐스트를 0.08ms 안에 완료.
* **rundll32 100% 안전 호출**:
  ```cmd
  rundll32.exe ScreensaverCore.dll,ApplyScreensaverSettingsRundll32 1,Mystify.scr,300,1
  ```
* 상단 헤더의 **[💎 DLL Core]** 버튼을 클릭하면 C-ABI 명세, 에러 코드, 컴파일 가이드 및 아키텍처 다이어그램을 언제든지 열람할 수 있습니다.

## 5. 스크립트 인코딩 및 호환성 사양

본 프로그램이 생성하는 배치 스크립트는 Windows 커맨드 프롬프트(cmd.exe) 환경에서 가장 안정적으로 동작하도록 아래 사양을 준수합니다.

- **줄바꿈 (Line Ending)**: `CRLF (\r\n)` - Windows 표준 개행
- **문자 인코딩 (Encoding)**: `UTF-8` (BOM 없음)
- **코드페이지 자동 전환**: 스크립트 상단에 `@chcp 65001 >nul` 구문이 삽입되어 한글이 포함된 에러 메시지 및 출력문이 깨짐 없이 표시됩니다.

## 6. 자주 묻는 질문 (FAQ) & 문제 해결

### Q1. 직접 만든 `.scr` 파일을 Windows 11에 어떻게 적용하나요?
> **A:** 스튜디오에서 내려받은 ZIP 압축을 푼 뒤 `build.bat`을 실행하여 생성된 `.scr` 파일을 마우스 우클릭하고 **[설치]**를 누르거나, `C:\Windows\System32\` 폴더에 복사해 넣으면 Windows 화면 보호기 목록에서 바로 선택할 수 있습니다.

### Q2. 듀얼 모니터에서 보조 화면이 주 화면으로 이동하거나 잘리는 현상이 왜 발생하나요?
> **A:** WinForms의 기본 창 최대화(`FormWindowState.Maximized`)를 사용할 때 OS가 강제로 주 화면으로 창을 이동시키기 때문입니다. 본 스튜디오에서 생성하는 코드는 `FormStartPosition.Manual`과 `Bounds = screen.Bounds`, `FormWindowState.Normal` 및 `SetProcessDpiAwareness(2)`를 적용하여 이 문제를 완벽히 차단합니다.

### Q3. `.bat` 파일을 내려받을 때 지정한 폴더가 아닌 다운로드 폴더에 저장되나요?
> **A:** 현재 버전에서는 Rust 백엔드가 네이티브 파일 다이얼로그(`rfd`)를 직접 제어하여 사용자가 지정한 위치에 영구적으로 안전하게 저장됩니다.

### Q4. 다른 PC에 배치 파일을 전달하여 실행할 수 있나요?
> **A:** 네, 내보내기한 `.bat` 파일은 단독 실행 가능한 Windows 스크립트이므로 다른 Windows 10/11 PC에서도 동일하게 실행하여 화면 보호기 설정을 일괄 적용할 수 있습니다.
